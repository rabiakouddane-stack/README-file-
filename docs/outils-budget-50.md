# Les outils avec un budget maximum de 50 € par mois

> ⚠️ **Règle importante** : beaucoup d'outils gratuits **interdisent l'usage commercial** ou ajoutent un **filigrane**. Une chaîne YouTube monétisée, c'est un usage commercial. Pour les étapes qui se voient dans la vidéo (images, animations, voix), il faut donc vérifier la licence. Les prix et les conditions changent souvent : **l'agent Veille les revérifie chaque mois**.

| Étape | Outil | Coût | Remarque |

| Animation vidéo | **Kling AI** (crédits gratuits chaque jour, ou petit abonnement) ; Hailuo/MiniMax (crédits gratuits) ; Google Veo (selon l'offre Gemini) | 0 à 10 €/mois | ⚠️ La version gratuite met souvent un filigrane : l'abonnement le plus bas est **le seul vrai achat important** |

## Budget type

| Configuration | Coût mensuel |
|---|---|
| **Démarrage 100 % gratuit** (ta voix + crédits gratuits quotidiens + CapCut) | **0 €** (production lente, filigranes possibles sur la vidéo) |
| **Conseillée** : petit abonnement vidéo (Kling ou équivalent) + ta voix | **environ 10 à 15 €** |
| **Confort** : vidéo + ElevenLabs Starter + un abonnement image | **environ 25 à 40 €** |

👉 Je recommande la configuration **conseillée (10 à 15 €)**. On utilise les crédits gratuits pour tester, puis on paie seulement la génération vidéo.

## Astuces pour économiser les crédits
1. **Valider le script avant de générer** : on ne paie jamais une vidéo dont l'histoire n'est pas validée.
2. **Image d'abord, vidéo ensuite** : on génère 2 ou 3 images (gratuites), on choisit la meilleure, puis on l'anime une seule fois.
3. **Plans réutilisables** : le salon, Alya qui marche, la famille réunie… On construit une bibliothèque de plans qu'on réutilise d'un épisode à l'autre.
4. **Plans fixes et mouvements lents** : ils réussissent du premier coup bien plus souvent (et ça correspond à notre style calme).
