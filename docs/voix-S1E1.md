# Voix de l'épisode S1E1 « Bienvenue Amir ! » (ElevenLabs)

## Réglages ElevenLabs
1. Va dans **Text to Speech** (Synthèse vocale).
2. **Modèle** : *Eleven Multilingual v2*, qui donne le meilleur français.
3. **Réglages de la voix** :
   - Stability (stabilité) : **50 %**
   - Similarity (ressemblance) : **75 %**
   - Style : **0**
   - Speed (vitesse) : **0,90**, un peu plus lent pour les petits
4. Choisis une voix dans la **Voice Library** (bibliothèque de voix), filtre « French ». Garde **toujours la même voix** pour chaque personnage, dans tous les épisodes.
5. Télécharge chaque réplique en MP3 et nomme-la comme dans le tableau.

> ⚠️ Pour monétiser la chaîne, il faut l'offre **Starter** (environ 5 $/mois). L'offre gratuite n'autorise pas l'usage commercial.
> 💡 Pour les pauses, écris `...` dans le texte, ou génère deux fichiers séparés.

| **Papa** | Homme jeune, chaleureux, calme |
| **Ma** | Femme, chaleureuse, un peu plus mûre |
